# buidlers brand system

buidlers is a web3 + AI ecosystem. The brand voice is that of a builder-rebel: technical, ethical,
community-first, and radically anti-hype. The aesthetic comes from the terminal — code syntax IS
the voice.

---

## identity

- **Brand name:** always `buidlers` — lowercase, no exceptions. Never "Buidlers", "BUIDLERS", or "Buidler's"
- **Logo mark:** `buidlers|` — the cursor bar `|` is a signature element, use it in social/Twitter contexts
- **Domain:** buidlers.org
- **Language:** Spanish-primary; bilingual ES/EN acceptable

## writing rules (estilo comunicacional)

These rules create the terminal/console aesthetic that defines buidlers writing.

### punctuation & syntax

1. **Semicolons replace periods** — every statement ends with `;` not `.`
   - ✅ `construir soberanía es un acto de resistencia;`
   - ❌ `construir soberanía es un acto de resistencia.`

2. **Lowercase sentence starts** — never capitalize the first word (console aesthetic)
   - ✅ `la privacidad no es una función, es una base ética;`
   - ❌ `La privacidad no es una función, es una base ética;`

3. **Programming punctuation** — use `{ }`, `[ ]`, `-`, `:`, `_` to group or close ideas
   - `ecosistema híbrido {físico y virtual}`
   - `buidl_mode=true`

4. **Cursor mark in social** — append `|` after `buidlers` in Twitter/short-form contexts
   - `buidlers|` as a signature

5. **Code block framing** — use `init {}`, `vision {}`, `# comment` structure for key brand statements

### language patterns

Use code metaphors naturally — they're not decoration, they're vocabulary:

| Code syntax | Brand usage                                                   |
| ----------- | ------------------------------------------------------------- |
| `//`        | inline clarification: `web3 + ia // autonomía == por_defecto` |
| `==`        | equivalence: `privacidad == derecho`                          |
| `→`         | consequence/result: `buidl_mode=true → guiar sin jerarquías`  |
| `{}`        | grouping: `{físico y virtual}`                                |
| `#`         | comment / subtitle prefix: `# esto es lo que creemos`         |
| `init {}`   | manifesto/opening block                                       |
| `vision {}` | vision statement block                                        |

Natural vocabulary: compilar · ejecutar · nodo · sistema · algoritmo · fork · init · deploy · commit ·
red · pull request · merge · stack · loop · debug · output · runtime

## correct vs. incorrect messages

### ✅ correct — how buidlers speaks

```
en un mundo donde los datos son moneda, construir soberanía es un acto de resistencia;

la innovación no nace del control, sino de la colaboración entre humanos y máquinas;

nuevas herramientas descentralizadas para quienes eligen construir sin pedir permiso;

la privacidad no es una función, es una base ética. todo lo demás se construye encima;
```

### ❌ incorrect — these break brand identity

| Wrong message                                                      | Why it fails                                                                                 |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `¡Revolucionando la tecnología con IA y Web3! 🚀`                  | Hype language + emojis + exclamation marks. buidlers inspires reflection, not hype.          |
| `Buidlers Realm: donde la innovación nunca se detiene.`            | Generic ad copy. No ethics, community, or sovereignty. Capitalized brand name.               |
| `Regístrate ahora y sé parte de la comunidad que cambia el mundo.` | Traditional marketing CTA. buidlers doesn't "sell" belonging — it invites building together. |

**Avoid at all times:**

- Exclamation marks (`!`) in copy
- Emojis in brand copy (only acceptable in casual community chat if user context demands)
- Hype words: "revolucionario", "disruptivo", "game-changer", "nunca se detiene"
- Capital letters at sentence starts
- Periods as sentence endings
- Generic CTAs: "únete ahora", "regístrate", "descubre más"

## how to apply this skill

**When generating content:**

1. Write in Spanish by default (bilingual acceptable)
2. Open with lowercase; close with `;`
3. Use code syntax metaphors where natural (`//`, `==`, `→`, `{}`, `#`)
4. Ground the message in at least one value (soberanía, ética, autonomía, privacidad, colaboración)
5. Avoid all hype language, emojis in copy, exclamations, and traditional marketing patterns
6. For social posts: consider `buidlers|` cursor signature

**When reviewing content:**

- Flag: capital letters at sentence starts
- Flag: periods instead of semicolons
- Flag: exclamation marks or emojis in copy
- Flag: hype/promotional language ("revolucionando", "únete ahora", "cambia el mundo")
- Flag: generic ad copy without brand values embedded
- Suggest: on-brand rewrites using the correct patterns above

**When asked about colors:** reference the semantic color-coding system — explain which color maps
to which content type and why (code analogy)

**When asked about typography or layout:** provide the exact specs from the tables above
